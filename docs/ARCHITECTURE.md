# Обзор проекта YaCut

Этот документ кратко объясняет ключевые части кода: инициализацию приложения, вьюхи, формы, API и обработчики ошибок. Дополнительно описана генерация коротких идентификаторов и асинхронная загрузка файлов на Яндекс.Диск.

## Инициализация (`yacut/__init__.py`)

- Создаётся экземпляр `Flask` и настраиваются конфигурации:
  - `SQLALCHEMY_DATABASE_URI` читается из переменной окружения `DATABASE_URI` (SQLite по умолчанию).
  - `SECRET_KEY` — из `SECRET_KEY` (dev-значение по умолчанию).
  - `DISK_TOKEN` — OAuth-токен Яндекс.Диска.
- Инициализируется `SQLAlchemy` (объект `db`). `Flask-Migrate` подключается опционально — при наличии пакета.
- Регистрируются блюпринты:
  - `main` (пользовательский интерфейс) из `yacut/views.py`.
  - `api` (REST API) из `yacut/api.py`.
- Регистрируются обработчики ошибок (см. ниже).
- В окружение Jinja добавляется глобальная функция `now` для отображения текущего года в футере.

## Вьюхи (`yacut/views.py`, блюпринт `main`)

Основные маршруты UI:
- `GET/POST /` — `index_view`
  - Форма укорочения ссылок: обязательное поле `original_link`, необязательное `custom_id`.
  - Проверки:
    - `custom_id` ≤ 16, только `[A-Za-z0-9]`.
    - Значение `files` зарезервировано.
    - Уникальность `custom_id` в БД.
  - Если `custom_id` не задан — генерируется автоматически функцией `get_unique_short_id()` (6 символов).
  - Результат сохраняется в модель `URLMap` и показывается пользователю.
- `GET /<short_id>` — `redirect_view`
  - Редиректит на оригинальный URL из БД или отдаёт 404 (через `first_or_404`).
- `GET/POST /files` — `files_view`
  - Асинхронная загрузка одного или нескольких файлов на Яндекс.Диск через `aiohttp`.
  - Шаги:
    1) Запрос upload-URL к API Диска (`/disk/resources/upload`).
    2) Загрузка файла `PUT` по выданной ссылке.
    3) Получение download-URL (`/disk/resources/download`).
  - После успешной загрузки отображаются пары «имя файла — ссылка скачивания».
  - Требуется `DISK_TOKEN` в окружении.

## Формы (`yacut/forms.py`)

- `URLForm` (главная страница):
  - `original_link` — обязательное поле, валидатор `URL`.
  - `custom_id` — необязательное, валидаторы: `Length(1, 16)`, `Regexp('^[A-Za-z0-9]*$')`.
- `FileUploadForm` (страница `/files`):
  - `files` — обязательное поле множественной загрузки.

## API (`yacut/api.py`, блюпринт `api` с префиксом `/api`)

- `POST /api/id/` — создание короткой ссылки:
  - Тело запроса JSON: `{ "url": string, "custom_id"?: string }`.
  - Ошибки:
    - Пустое тело / не JSON — `400`, `{ "message": "Отсутствует тело запроса" }`.
    - Нет `url` — `400`, `{ "message": '"url" является обязательным полем!' }`.
    - Некорректный `custom_id` (длина/символы/`files`) — `400`.
    - Конфликт `custom_id` — `400`, `{ "message": "Предложенный вариант короткой ссылки уже существует." }`.
  - Успех: `201`, `{ "url": original_url, "short_link": "http://host/<short>" }`.
- `GET /api/id/<short_id>/` — получение оригинального `url`:
  - 200: `{ "url": original_url }`.
  - 404: `{ "message": "Указанный id не найден" }`.

API соответствует примерам из `openapi.yml` и коллекции Postman в `postman_collection/`.

## Обработчики ошибок (`yacut/error_handlers.py`)

- Регистрируется обработчик `404` для UI, который рендерит `templates/404.html`.
- При необходимости можно расширить: разные ответы для API (JSON) и UI (HTML), проверяя `request.accept_mimetypes` или префикс пути.

## Модели (`yacut/models.py`)

- `URLMap`:
  - `id`: `Integer`, PK
  - `original`: `String(2048)`, not null — исходный URL
  - `short`: `String(16)`, unique, not null — короткий идентификатор
  - `timestamp`: `DateTime`, по умолчанию `datetime.utcnow`

## Утилиты (`yacut/utils.py`)

- `get_unique_short_id(length: int = 6) -> str`:
  - Генерирует случайный идентификатор из `[A-Za-z0-9]`.
  - Исключает зарезервированные значения (например, `files`).
  - Проверяет уникальность по БД (`URLMap.short`). При коллизии генерирует заново.

## Шаблоны (`yacut/templates/`)

- `base.html` — базовый шаблон, подключает `includes/header.html` и `includes/footer.html`.
- `index.html` — главная страница с формой сокращения URL.
- `files.html` — форма множественной загрузки, таблица с короткими ссылками.
- `404.html` — собственная страница 404.

## Конфигурация и запуск

- Зависимости — `requirements.txt`. Для асинхронной загрузки используется `aiohttp`.
- Переменные окружения:
  - `DATABASE_URI` — строка подключения SQLAlchemy (например, `sqlite:///db.sqlite3`).
  - `SECRET_KEY` — секретный ключ Flask.
  - `DISK_TOKEN` — OAuth-токен Яндекс.Диска.
- Тесты (`pytest`) проверяют схему БД, API и UI-потоки. В проекте 30 тестов, все проходят.

## Коротко о потоках

- UI: пользователь заполняет форму → валидация → сохранение `URLMap` → показ короткой ссылки.
- Редирект: запрос `/<short>` → поиск записи → `302` на `original`.
- Загрузка файлов: пользователь выбирает файлы → серия асинхронных запросов к API Диска → получение ссылок → вывод в таблицу.
- API: два эндпоинта, возвращающие JSON для создания и получения ссылок.
